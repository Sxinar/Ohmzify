## English

**Ohmzify** is a lightweight automation tool that transforms your standard terminal into a high-performance, smart, and aesthetic workspace. Don't waste time with manual configurations; modernize your shell in seconds.

### 🚀 Features
- **Zsh & Oh My Zsh:** Solid infrastructure for your terminal.
- **Auto-Suggestions:** Remembers your command history and suggests as you type.
- **Syntax Highlighting:** Provides real-time color feedback to prevent typos.
- **Agnoster Theme:** A professional-looking prompt showing Git branches and paths.

### 📦 Installation
```bash
git clone [https://github.com/Sxinar/Ohmzify.git](https://github.com/Sxinar/Ohmzify.git) && cd Ohmzify && chmod +x install.sh && ./install.sh

```

### 🎨 Visual Note

For the `agnoster` theme to display icons correctly, you should install a **Nerd Font** (e.g., *JetBrains Mono Nerd Font*) and set it as your terminal font.

## Türkçe
